# AquaDigital 💧

> **Transformando desperdício em solução tecnológica e sustentável para escolas públicas.**

O **AquaDigital** é um sistema automatizado e de baixo custo desenvolvido para captar, tratar, monitorar e reutilizar a água que seria desperdiçada no ambiente escolar. Através da integração de sensores inteligentes, automação e energia limpa, o projeto visa reduzir o impacto ambiental e os custos financeiros das instituições de ensino.

Este repositório contém o **MVP (Minimum Viable Product)** do painel de monitoramento em tempo real do sistema.

---

## 🚀 Sobre o Projeto

Nas escolas, grandes volumes de água são desperdiçados diariamente em torneiras esquecidas abertas, gotejamentos de bebedouros e condensação de aparelhos de ar-condicionado. O AquaDigital atua capturando esses recursos e direcionando-os para um reservatório integrado.

### Funcionalidades Principais:

* 
**Captação Inteligente:** Monitoramento do fluxo de água vindo de chuvas, ar-condicionados, pias e bebedouros.


* 
**Automação por Interruptores:** Controle direto sobre o sistema de filtragem e as bombas de irrigação.


* 
**Painel Analítico:** Gráficos em tempo real que indicam o volume de água reaproveitado na semana e a destinação do uso (como a irrigação da horta escolar).


* 
**Sustentabilidade Energética:** Planejado para operar utilizando energia solar fotovoltaica.



---

## 🛠️ Tecnologias Utilizadas

Este MVP foi construído utilizando tecnologias web padrão, dispensando a necessidade de instalações complexas:

* **HTML5:** Estruturação da interface do usuário.
* **CSS3:** Design responsivo e estilização dos interruptores e cards de sensores.
* **JavaScript (ES6):** Lógica de simulação de dados em tempo real (dados mockados) e manipulação do estado dos equipamentos.
* **Chart.js (via CDN):** Biblioteca utilizada para a renderização dos gráficos de linha e rosca.

---

## 💻 Como Rodar o Projeto

Como o protótipo foi modularizado em um arquivo único e utiliza dependências via CDN, a execução é extremamente simples:

1. **Baixe o código:** Clone este repositório ou baixe o arquivo `index.html`.
2. **Abra o arquivo:** Dê um duplo clique no arquivo `index.html` ou clique com o botão direito e selecione **"Abrir com"** seguido do seu navegador de preferência (Google Chrome, Mozilla Firefox, Microsoft Edge, etc.).
3. **Interaja com o painel:** * Desative o interruptor de **Filtragem** para ver os sensores de captação zerarem.
* Ative a **Bomba de Irrigação** para observar o nível do reservatório diminuir gradativamente enquanto a água é consumida.

* 
**Ambiental:** Redução drástica no consumo de água potável da rede pública através do reaproveitamento.


* 
**Econômico:** Alívio financeiro nas despesas de custeio da instituição de ensino.


*
